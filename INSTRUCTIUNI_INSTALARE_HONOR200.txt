PASUL 1: PREGĂTIRE TELEFON
  
  1. Activează Developer Options:
     Setări → Despre telefon → Apasă de 7 ori pe "Număr build"
  
  2. Activează USB Debugging:
     Setări → Sistem → Opțiuni dezvoltator → USB debugging (ON)
  
  3. Conectează telefonul la PC cu cablu USB
  
  4. Pe telefon, când apare prompt-ul:
     "Permite USB debugging?" → Bifează "Întotdeauna" → OK

PASUL 2: INSTALARE APLICAȚIE
  
  Deschide PowerShell în folder-ul proiectului și rulează:
  
  .\gradlew.bat installDebug
  
  Ar trebui să vezi:
  ✅ BUILD SUCCESSFUL
  ✅ Installing APK...
  ✅ Installed on 1 device

PASUL 3: TESTARE
  
  1. Deschide aplicația "EcoStep" pe Honor 200
  
  2. Vei vedea ecranul de login:
     ┌─────────────────────────┐
     │      🔒 (Lacăt)        │
     │       EcoStep          │
     │ Urmărește-ți impactul  │
     │                         │
     │  ┌───────────────────┐ │
     │  │ 🔒 Deblochează cu │ │
     │  │     Amprentă      │ │
     │  └───────────────────┘ │
     └─────────────────────────┘
  
  3. Click pe "Deblochează cu Amprentă"
  
  4. ✅ AR TREBUI SĂ APARĂ DIALOGUL MAGIC OS!
     (Nu mai vezi eroarea veche)
  
  5. Plasează degetul pe senzorul de amprentă
  
  6. ✅ Vezi Toast: "✅ Autentificare reușită!"
  
  7. ✅ Intri în Dashboard!
