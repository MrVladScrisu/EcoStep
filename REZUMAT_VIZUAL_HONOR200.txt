┌─────────────────────────────────────────────────────────────────────────────┐
│ A. PE TELEFON (Honor 200)                                                   │
└─────────────────────────────────────────────────────────────────────────────┘

  1. ✅ CONFIGUREAZĂ AMPRENTĂ (OBLIGATORIU)
  
     Setări → Securitate → Amprentă → Adaugă amprentă
     
     Pași:
     • Deschide Setări
     • Caută "Amprentă" sau "Biometric"
     • Adaugă amprentă nouă
     • Plasează degetul pe senzor (10-15 ori)
     • Confirmă
     • Testează deblocharea telefonului

  2. ✅ PERMISIUNI APLICAȚIE (AUTOMATE)
  
     • USE_BIOMETRIC - Acordat automat ✅
     • USE_FINGERPRINT - Acordat automat ✅
     
     Opționale:
     • CAMERA - Pentru AI detectare mâncare
     • INTERNET - Pentru Firebase
     • ACTIVITY_RECOGNITION - Pentru pași

┌─────────────────────────────────────────────────────────────────────────────┐
│ B. ÎN FIREBASE CONSOLE                                                      │
└─────────────────────────────────────────────────────────────────────────────┘

  1. ✅ ANONYMOUS AUTHENTICATION (OBLIGATORIU)
  
     https://console.firebase.google.com/
     
     Pași:
     1. Selectează proiect: "ecostep-7b5e0"
     2. Click: Authentication → Sign-in method
     3. Găsește: "Anonymous"
     4. Activează toggle-ul
     5. Click: "Save"
     
     Verificare: Status = "Enabled" ✅

  2. ⚠️ EMAIL/PASSWORD (OPȚIONAL)
  
     Doar dacă vrei login cu email:
     1. Authentication → Sign-in method
     2. Găsește: "Email/Password"
     3. Activează primul toggle
     4. Click: "Save"

  3. ⚠️ SHA-1 și SHA-256 (RECOMANDAT pentru Producție)
  
     Obține fingerprints:
     .\gradlew.bat signingReport
     
     Adaugă în Firebase:
     1. Project Settings (iconița cu roată)
     2. Tab "General"
     3. "Your apps" → com.example.ecostep
     4. "Add fingerprint" → Adaugă SHA-1
     5. "Add fingerprint" → Adaugă SHA-256
